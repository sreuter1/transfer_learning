To run training and inference, simply run the cell from top to bottom. The only hold-back is that you need to ensure that you have the competition files train/ and test/ downloaded to path=/root/.cache/kagglehub/competitions/ucsc-cse-144-spring-2026-final-project/

We used kaggle to download the tokens, but for security reasons those are deactivated and will not be usable by others. 

The results will be stored in a csv file that has the name of the image file in the first column and the label # in the second column.
